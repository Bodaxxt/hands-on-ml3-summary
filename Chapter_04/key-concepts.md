# Key Concepts – Chapter 4

| Term | Definition |
|------|------------|
| **Normal Equation** | Closed-form solution for linear regression |
| **SVD** | Singular Value Decomposition (used by Scikit-Learn) |
| **Gradient Descent** | Iterative optimization algorithm |
| **Learning Rate (η)** | Step size in gradient descent |
| **Epoch** | One pass through the entire training set |
| **Batch GD** | Uses all data per step |
| **Stochastic GD** | Uses one random instance per step |
| **Mini-batch GD** | Uses a small random batch per step |
| **Polynomial Regression** | Adding powers of features to fit non-linear data |
| **Learning Curves** | Plot of train/validation error vs training size |
| **Overfitting** | Model memorizes training data |
| **Underfitting** | Model is too simple |
| **Regularization** | Adding penalty to reduce overfitting |
| **Ridge (L2)** | Penalty = Σθ² |
| **Lasso (L1)** | Penalty = Σ|θ| |
| **Elastic Net** | L1 + L2 penalty |
| **Early Stopping** | Stop training at minimum validation error |
| **Logistic Regression** | Binary classification using sigmoid |
| **Softmax Regression** | Multiclass classification using softmax |
| **Log Loss** | Cost function for logistic/softmax regression |
| **Cross-Entropy** | Another name for log loss |
